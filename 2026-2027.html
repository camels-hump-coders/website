2026-2027 Season: BioBuzz

A new chapter in FIRST® Tech Chalange

Season Theme: BioBuzz

The 2026-2027 BioBuzz season is our first year moving from FIRST® LEGO® League into FIRST® Tech Chalange. This page will track the team's robot design, build progress, code work, outreach, and competition updates as the season develops.

What We Are Working On

Robot Build

Learning FTC-scale robot parts, drivetrain choices, wiring, and mechanisms that can handle a larger competition field.

Code

Building reliable driver controls, autonomous routines, sensors, and documentation for repeatable robot performance.

Team Systems

Organizing engineering notebooks, scouting, outreach, judging materials, and team roles for the new program.

Robot Design & Game

As we prepare for FTC, our focus for this year is to create a robot that can drive. We will try to add game-specific details once the season challenge is released.

    Our Goals for the year

  • Get the robot to drive
  • Learn about FTC
  • Driver practice routines and autonomous code experiments
